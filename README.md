# Анализ активности пользователей TechnologiCS за 30 дней

Интерактивный отчёт по загрузке сотрудников в корпоративной системе TechnologiCS.  
Проект подключается к базе данных Firebird/Interbase, обрабатывает логи сессий и строит визуализации в формате HTML с помощью Plotly.

---

## 📊 Что анализируется

- **Время работы** (в часах) за последние 30 дней (с устранением двойного учёта пересекающихся сессий).
- **Количество сессий** и **уникальных дней** работы по каждому пользователю.
- **Разбивка по подразделениям** (иерархия из таблицы `commontree`).
- Фильтрация только активных сотрудников (не уволенных, с конфигурациями TCS).

---

## 📈 Визуализация

Создаются три интерактивных графика (Plotly):

1. **Treemap** – размер плитки = часы, цвет = количество дней активности.  
   Показывает распределение по отделам и отдельным пользователям.

2. **Горизонтальная столбчатая диаграмма** – количество активных пользователей по отделам.

3. **Кольцевая диаграмма (pie)** – процентное соотношение активных пользователей по подразделениям (мелкие объединены в группу «Другие»).

Все графики сохраняются в один HTML-файл для просмотра в браузере.

## 🛠️ Технологии

- Python 3.7+
- `pandas` – обработка данных
- `pyodbc` – подключение к БД
- `plotly` – построение графиков

## ⚙️ Установка и запуск

### 1. Клонируйте репозиторий
git clone https://github.com/ваш-логин/technologics-analysis.git
cd technologics-analysis
### 2. Установите зависимости
bash
pip install -r requirements.txt
### 3. Настройте подключение к БД
В файле Аналзи.ipynb измените параметры подключения (server, database, uid, pwd) под свою среду.

### 4. Запустите Jupyter Notebook
bash
jupyter notebook Аналзи.ipynb
Выполните все ячейки – будет сгенерирован файл Активность пользователей системы TechnologiCS за 30 дней.html.

Данные извлекаются из таблиц LOG_SESSION, USERS, COMMONTREE, LOG_TABLE и др.

Перед запуском убедитесь, что у вас есть доступ к базе данных и драйвер ODBC для SQL Server.

Время сессий очищено от наложений (алгоритм схлопывания пересекающихся интервалов).
